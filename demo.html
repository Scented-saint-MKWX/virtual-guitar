🎓 Interactive Tutorial

Open the Application

Click the "Launch Application" button above or open index.html in your browser.

Allow Camera Access

When prompted, click "Allow" to grant camera permissions. The app needs to see your hands!

Position Your Hands

Fretting Hand (Left): Hold on the left side of the frame, over the virtual guitar neck.

Strumming Hand (Right): Hold on the right side of the frame.

Play Your First Note

With your left hand, pinch your index finger and thumb together near a string. With your right hand, quickly move your index finger down across the strings.

Try a Chord

Form an E Major chord: Index on fret 1 (string 3), Middle on fret 2 (string 5), Ring on fret 2 (string 4). Then strum!

Experiment with Tunings

Use the control panel on the right to switch between Standard E, Drop D, DADGAD, and more!

Add Percussion

With your strumming hand, quickly strike the guitar body area (dark brown zone) with your wrist to trigger a kick drum!

Core Algorithm: Radial Hitbox Detection

// For each fingertip (landmarks 4, 8, 12, 16, 20):
for (const tipIndex of [4, 8, 12, 16, 20]) {
    tip = landmarks[tipIndex]
    
    // Check if finger is "pressing" (pinch detection)
    distance3D = sqrt((tip.x - thumb.x)² + (tip.y - thumb.y)² + (tip.z - thumb.z)²)
    
    if (distance3D < pinchThreshold) {
        // Find which fret
        fretIndex = calculateFret(tip.x)
        
        // Check all strings within radius
        for (string of allStrings) {
            if (abs(tip.y - string.y) < fingerRadius) {
                activeStrings.add(string)
                frettedPositions[string] = fretIndex
            }
        }
    }
}

// Trigger audio for fretted notes
if (strummingDetected) {
    for (string of activeStrings) {
        note = transposeNote(string.baseNote, frettedPositions[string])
        sampler.playNote(note, velocity)
    }
}
